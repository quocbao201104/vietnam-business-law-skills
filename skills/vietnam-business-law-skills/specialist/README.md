# Specialist Depth

This directory is intentionally thin during architecture preflight.

Do not add specialist modules because a domain seems useful. Add one only when recurring runtime/eval evidence shows that a core BL track cannot handle the issue safely with stable reasoning plus live authority research.

A specialist is a temporary depth provider to an existing BL owner, not BL9/BL10 and not a final-answer owner.

Candidate future areas may include HS classification, preferential origin, transfer pricing, foreign borrowing, sector/product regulation, or specialist privacy. These are not pre-approved modules.
